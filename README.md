## 📦 Tech Stack

- **React 18** + **TypeScript** — Frontend framework
- **Vite** — Ultra-fast build tool
- **Recharts** — Beautiful data visualization charts
- **Lucide React** — Icon library
- **Framer Motion** — Animations
- **Vanilla CSS** — Premium dark theme (no Tailwind)
- **GitHub Pages** — Free hosting

## 🎮 Pages

1. **Dashboard** — Hero banner, live match with ball-by-ball, playoff race, upcoming fixtures
2. **Matches** — Full schedule with filters (Live/Scheduled/Completed), scorecards
3. **Standings** — Full points table with NRR trend chart and team performance
4. **Teams** — Team cards with detailed squad view
5. **Players** — Orange/Purple Cap, bar charts, all-player grid, comparison radar
6. **Predictions** 🆕 — AI win probability, radar comparison, key factors
7. **Auction** 🆕 — Interactive IPL auction simulator with budgets and bid history

## 🛠️ Setup

```bash
npm install
npm run dev       # Development server
npm run build     # Production build
```
